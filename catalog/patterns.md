# Pattern Catalog

Patterns are recognized solution approaches associated with Features. The catalog will grow through Feature and Pattern Issues.

## Authentication

- Email + Password
- OAuth
- Passkey
- MFA / 2FA
- Email Verification
- Password Reset
- Session Management
- Login Attempt Control

## Status

Authentication is the first proof-of-concept domain. Detailed pattern definitions should be created after the Standardization Model is agreed.
